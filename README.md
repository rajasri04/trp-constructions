# TRP Construction – Professional Next.js Website

A complete multi-page Next.js (App Router) website rebuild for TRP Construction with upgraded UI/UX and structured business content.

## Included pages

- Home
- About Us
- Management Team
- Services
- Residential Construction
- Commercial Construction
- Interior Design
- Ceramic
- Projects
- Careers
- Contact

## Business details included

- Founder details (T.R. Pazhamalai)
- Company legacy and vision/mission
- Services offered (Residential, Commercial, Interior Design, Ceramic)
- Office addresses (Registered + Branch)
- Contact email and phone numbers
- Client testimonials
- Brand partner list

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
